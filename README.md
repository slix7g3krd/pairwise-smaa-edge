# pairwise-smaa-edge

快速转身时，铁丝的边缘仍然在闪，边缘检测用固定的亮度阈值，暗部细线根本检不出来；只对亮度通道做检测，红绿相邻的色块边缘完全没处理；对角方向的锯齿被当成水平边，混合方向算反后边缘更碎；检测结果做了时域累积，移动时拖出一圈残影；SMAA 放在 TAA 之前，时域抖动把边缘图案打散，抗锯齿反而失效；分辨率切换后搜索步长没变，4K 下边缘检测范围太小；HDR 高光在检测前没做色调映射，整片霓虹被当成边缘；混合权重没有归一化，交叉处叠加出第三条亮边；检测在 sRGB 空间做，暗部梯度被放大，噪点被当成边缘；半透明物体的边缘和背景混在一起，透明通道没有参与检测。render/smaa_edge.py 是核心，tests/test_smaa_edge.py 15个红。要修的是：自适应阈值；三通道检测；对角图案；不做时域累积；放在 TAA 之后；按分辨率缩放步长；tonemap 后检测；权重归一；线性空间；透明单独处理。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
